# Last Train Out

A one-phone deduction game for the family table. Everyone has something to hide; one of you is the murderer. Find them before the Last Train Out leaves the pile.

Open the GitHub Pages address on your phone once with signal, then add it to the home screen. After that it opens and plays with no internet. Scores live on the phone; use **Copy scores** after each game and paste them into Notes as a backup.

When you change `index.html`, bump `VERSION` in `sw.js` (for example `lto-v2`) so phones pick up the new version.
